## Главное правило по цифрам

Проект **ничего не заработал и ничего не сэкономил**. Все суммы — это расчёт
по формулам на данных пилота, то есть *потенциальная* экономия при описанных
допущениях. В презентации и в устной защите деньги называются «расчётной» или
«потенциальной» экономией, никогда — фактической.

Это не осторожность ради осторожности: любой вопрос жюри «а вы это правда
сэкономили?» с ответом «нет, это расчёт» проходит спокойно, а с ответом «да»
превращается в провал по критерию технической защиты.
